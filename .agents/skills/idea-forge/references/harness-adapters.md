# Deep-mode dispatch

The main session owns the interview and selection. Pass a generator only the confirmed brief, existing capabilities, binding constraints, its assigned operator, and a request for short causal sketches. Hold back other candidates and the coordinator's obvious-answer list. Workers return text and the main session handles any files.

- **Codex.** If delegation is available and permitted, use the host's subagent tool. Start with a standalone brief and no inherited history when the host supports that choice. Gather replies before synthesis.
- **Claude Code.** If available and permitted, dispatch general-purpose subagents through the Agent tool in a single parallel batch. Use a self-contained prompt per worker. Keep the skill's interview in the parent session. Forking the whole skill would move the user-facing conversation into a worker.
- **Wave two.** Give a fresh worker the brief and the overlooked dimension. Give a worker refining an idea only the seed it needs. Provide the critic with the brief and anonymized candidates after generation.
- **Fallback.** If fresh contexts are unavailable, use separate passes in the current session with different operators and describe them accurately. Quick Mode uses this path by design. If Python is unavailable, group mechanisms or compare finalists directly using the reference rubrics.
